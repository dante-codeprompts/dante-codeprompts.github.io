# CYBERCELL: LIFE PROTOCOL — вертикальный срез

Версия 0.1. Работает в браузере Android. Хостинг — GitHub Pages.

## Что реализовано
- Полный цикл дня: утро → день → вечер → ночь → новый день
- 45+ карточек с условиями и эффектами
- Киберпсихоз 0–100 с порогами
- 5 фракций и 3 NPC с отношениями
- Отложенные события и флаги
- 4 режима: карточный, бюрократия, взаимодействие, кат-сцена
- Автосохранение в localStorage
- 4 концовки

## Установка на GitHub Pages

1. Создай публичный репозиторий `cybercell`.
2. Загрузи 5 файлов: `index.html`, `style.css`, `data.js`, `game.js`, `README.md`.
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `root` → Save.
4. Через 1–2 минуты открой `https://ТВОЙ_ЛОГИН.github.io/cybercell/` на телефоне.

## Как играть
- Открой ссылку в Chrome на Android.
- Добавь на главный экран (меню Chrome → «Добавить на главный экран»).
- Играй свайпами/тапами по вариантам.

## Как добавлять контент
Всё в `data.js`. Скопируй любой объект карточки и измени.
Поля:
- `id` — уникальный
- `cat` — категория (заголовок над названием)
- `title`, `desc` — текст
- `req` — условия появления
- `opts` — варианты, у каждого `t` (текст) и `e` (эффекты)
- `w` — вес (шанс выпадения)
- `once` — если `true`, выпадет один раз за жизнь
- `cd` — кулдаун в днях

## Эффекты
- `stats: { health, stress, clarity, hunger }` — от -100 до +100
- `credits` — деньги
- `cyber` — киберпсихоз
- `flags_set`, `flags_remove`
- `rel: { v, kestrel, mira }`
- `faction: { ether, claw, stream, lotus, free }`
- `counter` — счётчики
- `schedule` — отложенное событие

## Тестирование
Открой в Chrome на Android, введи `chrome://inspect` на ПК — увидишь консоль.
Или просто играй и записывай баги.
